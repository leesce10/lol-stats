# 교전 숫자 근거 표시 (Fight Stats)

> 작성 2026-06-12. 오브젝트 교전 카드에 "유리/불리"만 보여주던 걸,
> **왜 그런지(인원·레벨·템골드 차)** 숫자 근거 + 행동 지시까지 보여주도록.
> 로드맵 P1-2.

---

## 1. 목표 / 왜

- 지금: 오브젝트 마커에 판정 칩(`유리`/`불리`)만 뜸 → 초보는 "왜?"를 모름.
- 목표: **근거 숫자 3개(인원·레벨·템골드 차) + 한 줄 행동 지시**를 카드에 표시.
- 효과: 신뢰도↑(판단 근거 노출), 학습 효과↑(왜 유불리인지 자연 습득) — 우리 차별점(초보 코치)에 부합.
- **새 데이터 소스 0**. `fight-analysis`가 이미 다 계산함. 안 보내던 값을 보내고 그리기만.

---

## 2. 데이터 (이미 있음)

`fight-analysis.ts` 응답(`res`)에 전부 존재:
- `my.effective`, `enemy.effective` — 교전 시점 실질 인원(0~5, 0.5 가능)
- `my.lateReturns`, `enemy.lateReturns` — 제때 못 오는 사망자 수
- `avgLevelDiff` — 평균 레벨 차(우리−적), 소수1자리
- `goldDiff` — 아이템 골드 가치 차(우리−적)
- `verdict` — 매우유리~매우불리 (표시·색상 기준)

현재 `pushFight()`는 `{key, objective, verdict, reason, secondsTo}`만 전달 →
**여기에 위 숫자들을 추가**해야 함.

---

## 3. 표시 항목 & 규칙

마커(아이콘) 오른쪽 미니 패널에 판정 칩 아래로:

1. **인원** — `5 : 4` (내 : 적, effective 반올림). 한쪽이 복귀 못 하면 `(적 1 복귀✗)` 꼬리표.
2. **레벨** — `+1.0` / `-0.5` (avgLevelDiff). |차| < 0.3이면 `0`.
3. **템골드** — `+2.4k` / `-800` (goldDiff, 1000↑은 k표기, 반올림 100단위).
4. **행동 지시 1줄** — verdict별 고정 문구:
   - 매우유리: `지금 강하게 들어가세요`
   - 유리: `시야 잡고 시작하세요`
   - 호각: `신중하게, 무리 금지`
   - 불리: `지금은 피하세요`
   - 매우불리: `절대 싸우지 마세요`

**색상**(각 줄 개별):
- 우리 유리(+) = 녹(`#7ef0b0`), 적 유리(−) = 적(`#ff9f9f`), 0/호각 = 회(`#c8cfe0`).
- 행동 지시는 verdict 색(판정 칩과 동일 팔레트).

**표시 타이밍**: 숫자가 도착한 뒤(분석 1회 완료)부터 패널 노출. 그 전(아이콘만
내려/올라오는 초기)엔 판정 칩·숫자 없이 아이콘+카운트다운만. 즉 빈 값일 땐 칩 숨김.

---

## 4. 레이아웃 (좁은 240px 창 대응)

- 마커 아이콘은 세로선(left:60)에 그대로. **숫자 패널은 아이콘 오른쪽 고정**
  (판정 칩과 같은 방식, `position:absolute; left:54px`). 위/아래로 이동(상단/하단 정차)해도
  패널은 아이콘 기준 우측에 붙어 같이 움직임 → 창 밖으로 안 나감.
- 패널 폭 ~150px(60→210, 창 240 안), 폰트 11~12px, 줄 간격 좁게.
- 구조(예):
```
        ┌ 유리 ┐                ← 판정 칩(기존)
[아이콘] 인원 5:4 (적1 복귀✗)
        레벨 +1.0
        템골드 +2.4k
        시야 잡고 시작하세요     ← 행동 지시
```
- 카운트다운(`f-sec`)은 소환 전에만, 소환 완료(spawned)되면 숨김(기존 그대로).
  숫자 패널은 소환 전/후 모두 표시(판단 근거니까).

---

## 5. TTS 연동 (선택)

현재 교전 TTS(`buildFightTts`)는 지배 요인 1개를 정성적으로 말함
("적 1명이 복귀 못했어요"). 옵션:
- (a) **그대로 두기** — 숫자는 화면, 음성은 정성(초보엔 음성에 숫자 나열은 과함).
- (b) **숫자 한 개만 추가** — "골드 2천 앞서요" 정도. 과하면 역효과.
→ 기본은 (a) 권장. 화면=숫자, 음성=한 줄 정성. (이번 작업 범위는 **화면 표시**.)

---

## 6. 엣지 케이스

- 분석 전/실패 → 숫자 없음: 패널·칩 숨김(아이콘만).
- effective 소수(.5): 인원은 반올림 정수로 표기(`4.5→5`)하되, 색/판정은 원본 유지.
- goldDiff 작을 때(<300): `0`으로 표기(잡음 줄이기).
- 같은 마커가 상단(전령→바론 교체)으로 갱신될 때 숫자도 함께 갱신.
- 데모(`?demo`)에도 숫자 예시 넣어 미리보기 확인 가능하게.
