# 인게임 오버레이 — 경쟁 지형 & 개선 로드맵

> 작성 2026-06-12. 우리 오버레이(lol-overlay, Overwolf)의 경쟁 환경 조사 +
> 신규 기능 / 기존 기능 업그레이드 제안. 기획 원칙(reality-check, 페르소나,
> 차별화)에 맞춰 우선순위화.

---

## 0. 한 줄 요약

오버레이 시장은 **(A) 정보형 오버레이**(op.gg/U.GG/Blitz/Mobalytics/Porofessor)와
**(B) 2026년 폭증한 AI 실시간 음성 코치**(your.gg Lumi, HakkoAI, STATUP.GG,
LoL Sensei, RiftCoach, Sensii, Meeko, iTero)로 양분됐다. 우리는 둘 사이에 있고,
**"한국어 · 무료 · ToS 안전(Live Client Data만) · 초보 맞라인/교전 특화 음성 코치"**
라는 좁고 선명한 포지션으로 가야 이긴다. 기능을 넓히기보다 **이 좁은 영역을
경쟁자보다 깊고 정확하게** 파는 게 핵심.

### B. AI 실시간 음성 코치 (2026 급증·우리와 직접 경쟁)

| 서비스 | 방식 | 특징 / 약점 |
|---|---|---|
| **your.gg (Lumi)** | 이벤트 타임라인 + AI 음성 컴패니언. 마이크로 빌드/트레이딩 질문, 첫피·멀티킬 반응 | **우리가 모델로 삼은 직접 경쟁자.** 이미 코어템 타이밍/라인복귀/적 핵심템/교전유불리 + 음성 보유 |
| **HakkoAI** | VLM(화면 인식)으로 실시간 전술+정서 지원, 지연 ~4초 | 화면 판독 = **ToS 회색지대**, 영어, 구독 |
| **STATUP.GG** | 라이브 음성 코칭, "Simple 모드"로 초보 습관 형성 | 영어, 구독 |
| **LoL Sensei** | 조합/아이템/라인전략을 "왜"까지 실시간 설명, 레벨 적응 | 영어, 구독 |
| **RiftCoach / Sensii / Meeko / iTero** | 실시간 매크로/마이크로 코칭, 오버레이 + 위협 알림 | 대부분 영어·구독·화면판독 |

→ **시사점**: "초보용 음성 코치"는 더 이상 우리만의 빈 시장이 아니다. 단,
   거의 전부 **(1) 영어 (2) 구독 유료 (3) 화면 판독(ToS 위험) 또는 범용/모호**.
   우리의 빈틈 = **한국어 + 무료 + ToS 안전 + 맞라인/교전이라는 좁은 깊이**.

## 2. 우리의 현재 위치

**보유(인게임):**
- 게임 시작 조합 브리핑 (TTS, 한국어 자연어)
- 적 라이너 코어템 구매 알림 (아이콘 + 음성)
- 적 라인복귀 타이머 (부활+이동, 신발/라인 보정, 내 라인만, 타워깨지면 종료)
- 오브젝트 교전 유불리 (용/유충/전령/바론, 생성 전·후 음성 3단계, 방향 분리 UI)

**보유(웹, 아직 오버레이 미연동):**
- 맞라인 실전 가이드 (구간별), 위협 카드(콤보 체인 기반), 챔프별 데미지 밴드
- 5v5 조합 분석기, 챔피언 티어/통계

**차별점**: 한국어 음성 / 무료 / ToS 클린(Live Client Data·이벤트만) /
초보 맞라인·교전 집중 / 우리만의 위협·매치업 콘텐츠.

## 3. 격차 분석 — 그들에게 있고 우리에겐 없는 것

ToS(라이엇 정책: 클라이언트가 이미 가진 정보만, 화면 판독·위치추적·적 쿨다운 금지)
기준으로 분류:

**✅ ToS 안전 + 우리가 할 수 있는데 아직 안 한 것 (= 기회):**
- 파워스파이크 알림(레벨 6/11/16, 코어템 완성) — all_players로 가능
- 내 골드 → 다음 코어템 도달 알림 / 귀환 타이밍 — active_player.currentGold
- 챔프셀렉트 코치(카운터·매치업 난이도·빌드) — 우리 웹 데이터 연동
- 포스트게임 음성 리캡 — 종료 후 데이터
- 오브젝트 교전 시 팀 골드/레벨 차 숫자 노출 — fight-analysis에 이미 계산됨
- 적 코어템 → 위협/대응 한 줄 음성(우리 위협카드 연동)

**⚠️ 회색·불가 (하지 말 것):**
- 정글 캠프 타이머 — 클리어 이벤트가 Live Client Data에 없음 → 화면판독 필요(회색). 단,
  **고정 스폰 스케줄 기반 추정**은 가능(블루/레드 1:30 첫스폰 등) — 단순 알림 한정.
- 적 소환사 주문/궁 쿨다운 — 라이엇 명시 금지(이미 거절함)
- 적 미니맵 위치/로밍 감지 — 위치 데이터 없음 + 화면판독 회색(이미 거절함)
- 와드/CS 위치 기반 코칭 — 위치 데이터 없음

## 4. 신규 기능 제안 (우선순위)

표기: 임팩트(초보 도움) / 난이도 / ToS. **P0=다음, P1=그다음, P2=여유될 때.**

### P0 — 지금 바로 가치 큰 것

**P0-1. 파워스파이크 음성 알림 (내 라이너 + 나)**
- 적 라이너가 6/11/16 찍으면: "상대 궁 생겼어요. 무리한 교전 주의."
- 내가 6 찍고 적이 안 찍었으면: "지금 레벨 우위예요. 적극적으로 거세요."
- 적 코어템 완성 시(이미 감지) → 위협 한 줄 추가: "존야 샀어요. 궁 바로 쓰지 말고 빼세요."
- 데이터: all_players level/items. **ToS 안전.** 난이도 中.
- 차별점: Mobalytics는 텍스트 위젯, 우리는 **한국어 음성 + 초보용 대응 지시**.

**P0-2. 귀환/다음 코어템 골드 코치 (나)**
- "350골드만 더 모으면 [신발] 완성이에요. 지금 귀환 추천." / 라인 푸시 후 백 타이밍.
- 데이터: active_player.currentGold + 다음 빌드(웹). **ToS 안전.** 난이도 中.

**P0-3. 챔프셀렉트 음성 코치 (웹 매치업 데이터 연동)**
- 매치 시작 전(로비/로딩): "다리우스 상대예요. 초반 근접 교전 피하고, 점멸은 Q 피하는 데 쓰세요."
- 데이터: 우리 맞라인 가이드 + 위협카드(이미 보유). **ToS 안전.** 난이도 中(연동만).
- 차별점: 우리 고유 콘텐츠를 음성으로 → op.gg/U.GG의 텍스트 팁보다 초보 친화.

### P1 — 그다음

**P1-1. 포스트게임 음성 리캡 + 다음판 한 줄 과제**
- "이번 판 분당 CS 6.2, 데스 7회. 라인전은 좋았지만 한타에서 앞점프가 잦았어요.
  다음 판은 '먼저 들어가지 않기' 하나만 신경 쓰세요."
- 데이터: 종료 후 매치 데이터(Riot API). **ToS 안전.** 난이도 中.
- 차별점: 텍스트 분석은 U.GG/Mobalytics도 함. **음성 + 초보용 단일 과제 제시**가 신선.

**P1-2. 교전 카드에 팀 골드/레벨 차 숫자 + 셋업 지시**
- 현재 "유리/불리"만 → "골드 +2,400, 레벨 +1. 시야 먼저 잡고 시작하세요" 추가.
- 데이터: fight-analysis가 이미 numbersDiff/goldDiff 계산. **즉시 가능.** 난이도 下.

**P1-3. 오브젝트 처치 후 다음 행동 음성**
- 적 라이너 죽음 + 용 곧 스폰 → "상대 바텀 복귀 중. 지금 용 시야 잡으세요."
- 데이터: 이미 보유한 복귀 타이머 + 오브젝트 스케줄 조합. 난이도 中.

**P1-4. 음성 설정(카테고리 on/off, 볼륨, 음성 선택)**
- 일부 유저는 말 많은 걸 싫어함. 브리핑/아이템/교전/스파이크 토글.
- 작은 설정 창. 난이도 中. (유지율·리뷰 점수에 직접 영향)

### P2 — 여유될 때 / 차별화 심화

**P2-1. 정글 스폰 스케줄 알림(고정 시간 기반, 화면판독 X)**
- 협곡 첫 스폰/리스폰의 "고정 시간"만 알림(예: 칼날부리 등). 클리어 감지는 안 함(ToS).
- 한계 명확히: "정확한 리스폰 아님, 스폰 시각 안내"로 표기.

**P2-2. 첫 타워 골드/라인전 종료 코치**
- "첫 타워 깨졌어요. 이제 로밍·정글 합류로 시야 싸움 전환하세요." (이미 타워 이벤트 감지 중)

**P2-3. 마이크 질문(your.gg Lumi식) — 장기**
- "이 상대 어떻게 트레이딩해?" 음성 질문 → 우리 매치업 데이터로 답. STT 비용/정확도 검토 필요.
- your.gg가 이미 함 → 따라가기보다 P0~P1으로 기본기 다진 뒤.

## 5. 기존 기능 업그레이드

- **적 아이템 알림**: 아이템 단독 → **"왜 위험한지 + 대응"** 한 줄 동반(위협카드 연동). (P0-1과 묶음)
- **라인복귀 타이머**: 복귀 시점에 **행동 제안**("지금 라인 밀고 시야/오브젝트") 추가.
- **조합 브리핑**: 추상적 플랜 → **내 라인 매치업 구체 지시** 1줄 포함(P0-3과 연결).
- **교전 카드**: 숫자 근거 + 셋업 지시(P1-2).
- **TTS 품질/제어**: 카테고리 토글·볼륨(P1-4), 멘트 간결화(초보가 70초 안에 행동 가능하게).

## 6. 하지 말 것 (reality-check)

- op.gg/U.GG와 **정보량·정글타이머·스펠트래커 정면 승부** → 진다(데이터/인프라/인력 열세).
- **화면 판독(VLM/CV)** 기반 기능(적 위치·쿨다운·미니맵) → ToS 위험 + 1인 개발 부담.
- **영어/글로벌 동시 확장** → 한국어 초보 시장에서 먼저 이기고 나서.
- 기능 가짓수 늘리기 → "있으면 좋은" 기능 거절, "이것 때문에 쓴다"만.

## 7. 추천 실행 순서

1. **P1-2(교전 숫자 근거)** — 이미 계산된 값, 1시간. 즉시 체감↑.
2. **P0-1(파워스파이크 + 적 아이템 위협 대응)** — 핵심 차별점, 위협카드 연동.
3. **P0-3(챔프셀렉트 매치업 음성 코치)** — 우리 고유 콘텐츠 음성화, 진입부터 도움.
4. **P0-2(골드/귀환 코치)**.
5. **P1-4(음성 설정)** — 배포·유지율 전에 필수.
6. **P1-1(포스트게임 음성 리캡)** — 재방문 고리.

**관통 원칙**: 새 데이터 소스 추가가 아니라 **이미 가진 데이터(이벤트·아이템·골드·레벨)
+ 우리 웹 콘텐츠(매치업·위협카드)를 "한국어 음성 행동 지시"로 바꾸는 것**.
경쟁자가 영어·구독·화면판독으로 가는 길의 반대편(한국어·무료·ToS안전·초보행동지시)을 판다.
