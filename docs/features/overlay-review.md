## 기능별 현황 & 개선

### 1. 게임시작 조합 브리핑 (TTS, 2부)
- **동작**: 시작 직후 1부(적 조합 특성+이기는 법+내 라인밖 최대위협) → 3초 뒤 2부(내 라인 맞라인/바텀 듀오 콤보 + 우선순위). 한국어 여성.
- **한계**: ① 1회성 — 놓치면 다시 못 들음. ② 조합 분류(암살자/AD·AP)는 76챔프만. ③ 라인 폼(전적)은 mock(실데이터 아님). ④ 길이·톤 가끔 들쭉날쭉.
- **개선**: ① **리플레이**(트레이/단축키로 다시 듣기). ② 분류 데이터 173챔프 확대. ③ Riot Production 키 → 실제 전적 폼 반영. ④ 길이 컷·중요도 정렬.

### 2. 적 코어아이템 알림 (토스트 + 음성)
- **동작**: 시야에 보인 적이 새 코어템 완성 시 토스트 + TTS("상대 X가 Y 구매…"). 안정키+시야연속성 게이트로 중복/폭발 방지. DDragon 최신.
- **한계**: ① "코어" 판정이 단순(완성+1600골드↑) — 핵심 스파이크템 일부 누락/과알림 가능. ② **왜 위험한지 없음**(그냥 "샀습니다"). ③ 여러 개 동시 → 음성 겹침.
- **개선**: ① 아이템→**위협 한 줄**("존야 샀어요, 궁 바로 쓰지 마세요") 위협 데이터 연동. ② 코어 판정 정교화(주요 스파이크/신발 포함). ③ **TTS 큐**(겹침 방지). ④ (선택) 내 다음 코어템/스파이크 알림.

### 3. 적 라인복귀 타이머 (타임라인)
- **동작**: 사망 감지(deaths/respawnTimer) → 부활(정확)+이동(라인/신발 보정) 카운트다운 → "복귀" 2.5초. 내 라인만. 타워깨짐/16분 종료.
- **한계**: ① **이동시간 휴리스틱**(라인+5/신발-2 등 러프, 실측 검증 안 됨). ② 포지션 빈값(봇/블라인드) 폴백. ③ 복귀 후 "그래서 뭘?"이 없음.
- **개선**: ① 이동시간 실게임 튜닝. ② 복귀 임박 시 **행동 제안**("지금 갱/오브젝트 가세요"). ③ 포지션 미인식 대비.

### 4. 오브젝트 교전 유불리 (타임라인)
- **동작**: 용/유충/전령/바론 스폰 60초전~ 분석, 판정+숫자근거(인원/레벨/템골드)+행동지시. 상/하단 방향분리, 우선순위 교체, 살아있는동안 유지.
- **한계**: ① **스폰 스케줄 고정** — 현 패치와 다를 수 있음(장로·지역드래곤·공허유충 다중스폰 미반영). ② **교전 가중치 미검증**(러프). ③ 적 골드/레벨은 보이는 것만.
- **개선**: ① 스폰 스케줄 현패치 검증/갱신 + 장로/지역용/유충 다중스폰 처리. ② 가중치 실데이터 보정. ③ "왜 유불리" 더 구체화.

### 5. 오브젝트 교전 음성
- **동작**: 인스턴스당 60s/30s전·소환직후 3회, 지배요인+핵심숫자+권고.
- **한계**: 4번 스폰 정확도에 종속 + 여러 오브젝트면 빈번 + 겹침.
- **개선**: 4번 스케줄 정확도 + TTS 큐 + 빈도 조절(중요 오브젝트만).

### 6. 상황별 위협 / 맞라인 코칭 (데이터 계층)
- **동작**: 173챔프 상황별 위협(LLM+DDragon 실스킬), 56챔프 풀 맞라인, 20챔프 CC 듀오콤보, 76챔프 분류. 사이트·오버레이 공용.
- **한계**: ① **품질 편차**(LLM 생성, 검수 부분적). ② 패치 변동 미반영. ③ CC/프로파일 커버리지 제한.
- **개선**: ① **라인별 큐레이션**(원딜 파일럿식 — 공개 코칭 텍스트로 검수·강화). ② CC·프로파일 확대. ③ 패치 갱신 루틴.

## 전반(Cross-cutting) — 여기가 "부족한 느낌"의 핵심

- **A. 설정 UI 없음** ⭐ — 음성 on/off·볼륨·카테고리·표시 위치 조정 불가. 유지율·만족도 직결. **최우선.**
- **B. TTS 시스템** — 겹침(큐 없음), 반복, Edge TTS 톤. 큐/인터럽트 정책 + 멘트 정제 필요.
- **C. 창 배치** — 고정 좌표. 해상도/DPI/울트라와이드/맥 미검증. 적응형 + 드래그 조정.
- **D. 견고성** — API 끊김·재접속 처리 약함, 맥 자동업데이트 없음, 에러 핸들링 보강.
- **E. 데이터 신선도** — 스폰 스케줄/스파이크/티어 패치 갱신, 실데이터(Production 키).
- **F. 검증 부재** — 복귀 이동·교전 가중치·코어판정 등 휴리스틱이 실게임 검증 안 됨.
